https://andreiapessoaconfeitaria.com.br

`Cloudflare R2` `REST API`

- Sistema de pedidos

- Kanban de produção de pedidos

- Controle de produtos e categorias
- Sistema de cupons
- Dashboard de vendas
- Relatórios financeiros
- Integração com pagamentos
- Webhooks
- Cotação de entrega

- Configuração de ambientes development / beta / production

### Engenharia

até segurança, integrações externas, deploy e operação em produção.
